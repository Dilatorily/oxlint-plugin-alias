# Shareable Oxlint configuration files

The files in this folder were manually generated by executing the [Oxlint migration tool](https://www.npmjs.com/package/@oxlint/migrate) with the shareable configuration files from ESLint.

```bash
$ npx @oxlint/migrate --type-aware --with-nursery --details
```

The content of the migrated ESLint configuration file was defined as something similar to this:

```typescript
import eslint from '@eslint/js';
import { defineConfig } from 'eslint/config';

export default defineConfig([eslint.configs.recommended]);
```
